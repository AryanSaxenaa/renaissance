# Contributing

SerpApi hackathon project — live data via `src/server/serpapi/` only.

```bash
npm ci
npm run dev
```

Replay mode without `SERPAPI_API_KEY`. API `:3000`, Vite `:5173` (`/api` proxied).

- No invented numbers in briefs
- Server logging: `pino` (no `console.log`)
- Run `npm test` before pushing
